# CosmoFlix 🚀
DCIT 26 – Laboratory Exercise 10: React Native (Components, Navigation and Map)

A simple space/sci-fi movie app built with Expo, React Navigation (bottom tabs) and NativeWind (Tailwind).

## Run
Run these commands from the Expo project folder:

```powershell
cd "CosmoFlix"
npm install
npx expo start
```

Press `w` in the Expo terminal to open the web preview. The Expo project loads the app screens, components, data, and images from this folder's parent directory.
